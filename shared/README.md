# Shared

Language-neutral files used by more than one language version of the same project. Each project gets a subfolder with the same name as its language folders, for example `shared/foo/` for `python/foo/` and `go/foo/`.

Put only neutral material here, such as specs, READMEs, test fixtures, sample data, JSON schemas or API contracts. Do not put source code here that one language imports.
